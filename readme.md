# Minuterie pour planeur de vol libre
<!--<img align="left" width="80" height="80" src="https://github.com/fra589/WeTimer/blob/master/doc/images/WeTimer_logo.svg">-->
<p>
<img align="left" width="160" src="https://github.com/user-attachments/assets/872df7ed-3707-4356-96f7-7a71e1bc6638">

Basée sur une carte microcontrôleur WiFi ESP8266 de type Wemos D1 mini (34mm x 26mm), disponible pour quelques euros, la minuterie WeTimer permet de commander quatre servos (3 pour les éléments aérodynamiques mobiles plus 1 pour la gestion du crochet de treuillage) en fonction des différentes phases de vol du planeur.

La configuration se fait au travers d'un interface web accessible via smartphone avec une connexion WiFi.<br />
Cette connexion WiFi permet également d'activer la fonctionnalité de déthermalisation à distance (RDT) avec une portée d'une (a quelques) centaine(s) de mètres.
